## Issues Found

### 1. 18 Orphaned Groups (DATA_QUALITY_ISSUE)

**Severity**: Low  
**Impact**: 18 groups have no teacher (teacher User record deleted)  
**Groups affected**: Still have GroupMember records pointing to valid students  
**Root cause**: Teacher accounts deleted without cascading group cleanup  
**Fix**: `DELETE FROM "Group" WHERE "teacherId" NOT IN (SELECT id FROM "User")`  
**Risk**: Orphaned groups may confuse students who try to access them  

### 2. 784 AIUsage Records with NULL Status

**Severity**: Medium  
**Impact**: 62.8% of AI usage records lack success/error classification  
**Root cause**: AIUsage logging may not set `status` field on completion  
**Fix**: Audit AIUsage creation code to ensure `status: "SUCCESS"` or `status: "ERROR"` is always set  
**Risk**: Cannot calculate true AI success rate; 37.2% error rate may be inaccurate  

### 3. 713 Students Without Group Membership

**Severity**: Medium  
**Impact**: 36.5% of students have no teacher relationship  
**Root cause**: Self-registered students who never joined a class  
**Fix**: This is expected behavior (not a bug) — but consider prompting self-registered students to find their school/teacher  
**Risk**: These students have lower retention (4.3% D30 vs 24.1% for school-linked)  

### 4. 772 Phantom Schools

**Severity**: Low  
**Impact**: 78.3% of school names have no meaningful activity  
**Root cause**: Users type random school names during profile setup  
**Fix**: Add school name autocomplete or validation against known Indonesian schools  
**Risk**: Inflates "school" metrics; makes school-based analytics unreliable  

### 5. 106 School Name Collisions

**Severity**: Low  
**Impact**: Same school entered with different spellings (e.g., "SMP Santa Laurensia" vs "SMP Santa Laurensia Jakarta")  
**Root cause**: Free-text input without normalization  
**Fix**: Normalize school names during entry; merge duplicates  
**Risk**: School cluster counts are slightly inflated by duplicates  

### 6. 5 Users Without Profile Records

**Severity**: Low  
**Impact**: 5 users exist in User table but have no Profile record  
**Root cause**: Profile creation may have failed during registration  
**Fix**: Create Profile records for these 5 users  
**Risk**: Minimal — these users likely inactive  

### 7. 70.6% Users Without Avatar

**Severity**: Cosmetic  
**Impact**: 1,715 users have no profile picture  
**Root cause**: Avatar upload not required during registration  
**Fix**: Add default avatar or prompt during onboarding  
**Risk**: None — cosmetic only

## Not Issues (False Positives)

### "97.1% Teachers Have Zero Students"
**NOT a data issue** — this is a real activation problem. Teachers register but never create classes.

**NOT a data issue** — this is a real monetization problem. Only 6/465 initiated checkout.

### "37.2% AI Error Rate"
**PARTIALLY an instrumentation issue** — the error count is real, but success count is missing due to logging gaps.

### "80.9% Schools Are Single-User"
**PARTIALLY phantom data** — 78.3% are phantom, but the remaining schools show healthy activity.
