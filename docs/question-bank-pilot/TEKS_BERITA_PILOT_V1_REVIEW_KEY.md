## Per-item detail (for adjudication)

### TB-001 — correct **A**
- **Evidence**: "SMP Nusantara meresmikan perpustakaan digital pada Senin, 3 Maret 2025" (kalimat 1).
- **Distractor rationale (hypotheses)**: B = month swap during fast scan; C = cross-stimulus contamination (date from STIM-03); D = day swap.
- **Expected cognitive operation**: locate an explicitly stated date in the lead — no inference (R2).
- **Stimulus-dependence**: full — date exists only in STIM-01.

### TB-002 — correct **A**
- **Evidence**: lead (peresmian) + Ibu Ratna's purpose statement ("bertujuan menumbuhkan kebiasaan membaca siswa") form the main idea.
- **Distractor rationale (hypotheses)**: B = numeric salience (1.500); C = ceremonial surface detail; D = last-sentence-as-conclusion misreading.
- **Expected cognitive operation**: distinguish lead from supporting detail (claimed R3; F1 proposal → R2 gagasan literal).
- **Stimulus-dependence**: full.

### TB-003 — correct **A** (revised in P2.2 — key now verbatim-supported)
- **Evidence**: "Gerakan ini menyediakan 500 buku bacaan yang ditempatkan di pos ronda dan balai desa" (kalimat 2). The government only *launched* the gerakan; the gerakan *provides* the books — key avoids subject shift.
- **Distractor rationale (hypotheses)**: B = positive future claim read as fact; C = superlative judgment ("terbaik"); D = normative advice ("sebaiknya") read as fact.
- **Expected cognitive operation**: fact/opinion discrimination by text-verifiability (claimed R4; F1 proposal → R5 fakta/opini).
- **Stimulus-dependence**: full.

### TB-004 — correct **A**
- **Evidence**: "mengeluhkan kondisi sebagian buku yang sudah usang" + following hope for new books — the word means "menyampaikan keluhan tentang sesuatu."
- **Distractor rationale (hypotheses)**: B = context bleeding (following sentence about hoping for help); C/D = form-based guessing without reading the sentence.
- **Expected cognitive operation**: derive word meaning from sentence context (R3).
- **Stimulus-dependence**: full (context sentence exists only in STIM-02).
- **P2.2 note**: subskill remapped `READING_INFERENSI` → `READING_MAKNA_KATA` (canonical taxonomy); optional refinement (avoid root word "keluhan" in key) is non-blocking.

### TB-005 — correct **A**
- **Evidence**: two evidences — (1) 60 students planted 500 seedlings, (2) students cleaned plastic from the stream — jointly support environmental care.
- **Distractor rationale (hypotheses)**: B = "bagian dari program" misread as "pengganti program"; C = unsupported motive stereotype; D = action reversal.
- **Expected cognitive operation**: integrate two textual evidences into one conclusion (R4).
- **Stimulus-dependence**: full.

### TB-006 — correct **A**
- **Evidence**: direct quote — "Sebagian besar pengunjung adalah pelajar sekolah dasar."
- **Distractor rationale (hypotheses)**: B/C/D = personal experience/stereotype about library visitors replacing textual evidence.
- **Expected cognitive operation**: locate explicit "siapa" answer (R2).
- **Stimulus-dependence**: full.

### TB-007 — correct **A**
- **Evidence**: correct headline maps the lead (Pemerintah Desa Sukamaju meluncurkan gerakan).
- **Distractor rationale (hypotheses)**: B/C = sensational/contradictory headlines chosen for "interest" without text verification; D = wish-as-fact (hope read as event).
- **Expected cognitive operation**: apply headline convention to lead content (claimed R3; F1 proposal → R4 struktur).
- **Stimulus-dependence**: full.

### TB-008 — correct **B** (index 1 — only item not at index 0; D15 hygiene)
- **Evidence**: sentence 1 = lead (who-when-where core); sentence 2 ("Mobil perpustakaan itu membawa 800 buku cerita dan buku pengetahuan") elaborates the lead's claim = body.
- **Distractor rationale (hypotheses)**: A = "first sentence = lead" heuristic misapplied to sentence 2; C = content-as-summary pattern-match; D = function misattribution (when/where answers live in sentence 1).
- **Expected cognitive operation**: classify mid-text sentence function against inverted-pyramid structure (R4). Task was strengthened in P2.2 (was: locate the lead ≈ R2/EASY); F2 resolved.
- **Stimulus-dependence**: full.

### TB-009 — correct **A**
- **Evidence**: "sangat membantu" is an evaluative judgment delivered by Ibu Lestari under "Menurut Ibu Lestari" — an opinion, not verifiable from the text.
- **Distractor rationale (hypotheses)**: B/C/D = verifiable facts; students choosing them confuse "stated in text" with "opinion" — specifically D tests the "number = fact" bias; the item inverts the "quoted source = true" and "opinion only when signposted 'menurut'" misconceptions.
- **Expected cognitive operation**: identify an evaluative claim despite quoted framing (claimed R4; F1 proposal → R5 fakta/opini).
- **Stimulus-dependence**: full.

### TB-010 — correct **A** (revised in P2.2 — referent + key)
- **Evidence**: P2 contains two coordinate sentences — weekly deposit (s1) and use of proceeds for notebooks (s2); the key summarizes both.
- **Distractor rationale (hypotheses)**: B = first-sentence-is-main-idea heuristic; C = P1 idea; D = P3 idea.
- **Expected cognitive operation**: identify the topic of a specific paragraph, distinguishing from its own details and other paragraphs (claimed R3; F1 proposal → R2 gagasan literal).
- **Stimulus-dependence**: full. P2.2 restored the P1–P4 paragraph breaks so "paragraf kedua" exists in the delivered text.

### TB-011 — correct **A**
- **Evidence**: participants rose 30 → 90 and first-month proceeds (Rp350.000,00) funded a real purpose — consistent with growing interest.

- **Expected cognitive operation**: integrate two data points into a supported conclusion (R4).
- **Stimulus-dependence**: full.

### TB-012 — correct **A**
- **Evidence**: the text states roots "mengurangi risiko longsor" — a risk reduction; "dijamin tidak akan terjadi" overclaims beyond the evidence.
- **Distractor rationale (hypotheses)**: B/C/D = statements directly supported by the text; correct selection requires verifying support rather than scanning for familiar content; targets correlation→causation and guaranteed-outcome misconceptions.
- **Expected cognitive operation**: evaluate claim-support against textual evidence (R5).
- **Stimulus-dependence**: full.
