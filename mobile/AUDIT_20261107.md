# Audit statis mobile/ — 7 November 2026

Cabang: `feat/mobile-flutter-shell-20261106` (basis `ef3bd9c`).

## Batas audit ini
Dilakukan dengan membaca kode saja. Sandbox tidak bisa mengunduh Dart SDK dan Android SDK
(`storage.googleapis.com` ditolak), jadi `flutter analyze`, `flutter test`, dan
`flutter build apk --debug` **belum dijalankan**. Perubahan di bawah belum dikompilasi.

## Diperbaiki di patch ini
| Berkas | Masalah | Perbaikan |
|---|---|---|
| `webview_screen.dart` | `PopScope(canPop: false)` + tidak ada riwayat → tombol kembali Android tidak melakukan apa-apa, pengguna tak bisa keluar | `_goBack()` memanggil `SystemNavigator.pop()` bila tak ada riwayat |
| `webview_screen.dart` | Setelah offline lalu online, layar error tetap tampil sampai pengguna menekan "Coba Lagi" | Muat ulang otomatis saat koneksi pulih |
| `webview_screen.dart` | Tautan `mailto:` dan `tel:` diblokir diam-diam | Dibuka lewat aplikasi eksternal |
| `build.gradle.kts`, `settings.gradle.kts` | Plugin `google-services` dan Crashlytics tidak pernah diterapkan, jadi FCM/Crashlytics tidak mungkin aktif walau `google-services.json` ada | Diterapkan hanya bila `android/app/google-services.json` ada; build tanpa file itu tetap jalan |
| `pubspec.yaml` | `ios: true` untuk launcher icons / native splash padahal folder `ios/` tidak ada | Diubah ke `false` sampai iOS dibuat |
| `mobile/.gitignore` | Semua pola berawalan `mobile/` sehingga tidak pernah cocok (relatif ke folder mobile) | Pola dibetulkan; ditambah `key.properties`, `google-services.json`, `GoogleService-Info.plist`, keystore |

## Temuan yang belum diperbaiki (butuh keputusan atau data dari pemilik)
1. **Deep link `autoVerify` tidak akan lolos.** `app/api/assetlinks/route.ts` hanya menaut
   `com.bahasacerdas.arena` (TWA). Paket `com.bahasacerdas.app` belum terdaftar, dan
   `ANDROID_CERT_FINGERPRINTS` butuh sidik jari keystore yang belum ada. Mengubah ini berarti
   mengubah kode produksi web, jadi tidak saya sentuh.
2. **Upload berkas dari WebView** (avatar, karya) kemungkinan tidak membuka pemilih berkas di Android
   tanpa `setOnShowFileSelector` + paket pemilih berkas. Perlu diuji di perangkat fisik sebelum
   memutuskan dependensi.
3. **Izin kamera/mikrofon** diminta untuk semua halaman, bukan hanya JUMPA. Itu disengaja sementara
   karena UKBI Berbicara juga butuh mikrofon, tapi bertentangan dengan langkah 4 di
   `ANDROID_BUILD_RECOVERY_20261106.md`. Putuskan cakupannya.
4. **ID proyek Firebase tidak konsisten:** `firebase_config.dart` memakai `bahasa-cerdas-app`,
   `FIREBASE_STATUS.md` menulis `bahasacerdas-e18d6`. `FIREBASE_STATUS.md` juga mengklaim
   "Build APK debug: PASS" padahal dokumen recovery mencatat build gagal. Verifikasi ulang.
5. **Login Google** dibuka di peramban eksternal oleh `NavigationPolicy`, sehingga sesi tidak kembali
   ke WebView. Alur `?bc_app=1` harus menyembunyikan tombol Google atau memakai alur OAuth native.
6. `lib/features/shell/app_shell.dart` tidak dipakai di mana pun (kode mati).
7. Jangan jalankan `dart run flutter_launcher_icons`: konfigurasinya memakai `icon-512.png`
   penuh sebagai foreground adaptif dan akan menimpa ikon yang sudah ada.
